A fluid simulator written in python. It uses a grid of a handful of values to simulate the behaviors of a fluid. These values are pressure, density, and velocity. These are solved, and the density values are used to draw the fluid to the screen. Press G to enable or disable gravity, use the arrow keys to move the source-emitter, press 1-4 to change the view of the simulation. 1/2 show the density values, 3 shows the velocity values, and 4 shows the pressure.
